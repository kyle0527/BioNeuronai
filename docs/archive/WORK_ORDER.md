# 工作順序（使用者約定 · 不可顛倒）

> **範圍（2026-07-18 再次確認 · 不可縮小）**  
> 這 **5 個步驟是對「整個專案」**，不是對某一個功能、某一條主線、或某一份文件。  
> 任一步若只做了局部切片，**不得**宣稱該步驟「整案完成」。

> **唯一正確順序**  
> 1. **全部檢查完**（全專案新舊／現役盤點；能說清楚每一大塊：有沒有、缺什麼、要不要移）  
> 2. **該移的移回來**（全專案該回現役的能力，真的改 `src/` / `backtest/` / `config` / CLI 等，不是只寫 md）  
> 3. **調整**（全專案接線、契約、消殘留、模組間對齊）  
> 4. **修使用者手冊**（整套 `docs/manuals/` 可照做，不是只改一兩頁）  
> 5. **才**依照手冊真實操作（虛擬帳戶／Paper OK；不用 pytest）
